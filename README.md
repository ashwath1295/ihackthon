# ihackthon

Sample Next.js app (App Router, TypeScript, Tailwind CSS).

## Getting started

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

- `src/app/page.tsx` – home page
- `src/components/TaskList.tsx` – client-side task list
- `src/app/api/hello/route.ts` – sample API route (`GET /api/hello`)
